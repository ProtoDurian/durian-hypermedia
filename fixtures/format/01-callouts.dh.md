## Callouts

A callout is a note beside the text it is about. A note about the whole page is a callout too: put it under the title. It is a blockquote that opens with a bold marker. The marker picks the icon and the colour; the author never picks an icon.

> **Note:** a fact worth knowing, but not needed to follow the text.

> **Tip:** press :kbd[Ctrl+K] to search the docs.

> **Important:** the CLI sends every answer on every call.

> **Watch out:** a validate call replays the script with the deterministic state from before the question.

> **Security finding:** (an example, not a real finding) a security block sits on its own; the public LLM view drops it.
