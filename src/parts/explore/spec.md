#### Explore

```json explore query=".items[] | select(.qty > 1)"
{"items":[{"name":"tea","qty":2},{"name":"cup","qty":1}]}
```

A json, yaml, toml or csv fence with the bare word explore draws a foldable tree, counts, search that opens matching ancestors, path copying, a table for lists of objects, starter queries and a jq subset box. Every explorer has a two-button switch in its header, **Rich | Raw**: Rich (the default) is the tree, search and query box; Raw is the source as plain read-only text with line numbers, no search and no query. Raw JSON is the data pretty-printed with 2 spaces; raw YAML, TOML and CSV are as the author wrote them (trailing blank lines cut). The switch is two keyboard-reachable buttons (`aria-pressed`); the raw box is a focusable region that scrolls sideways at a phone width, shows 1000 lines and asks for more. A static or printed explorer shows neither the switch nor the raw view. Without explore it remains an ordinary fence. The author query= runs during parsing on the page budget. A reader query always receives a new budget, so a failed query does not spend the next one. The LLM reads the original data followed by the author query result. :::llm can replace it.

The query subset provides paths, iteration, select, map, pipes, arithmetic, arrays/objects, variables, conditionals, try, sorting/grouping, strings and a metered non-backtracking regex test. Unsupported syntax or functions are refused by name. Integer-looking object keys follow JavaScript order. CSV accepts quoted fields, doubled quotes and newlines in fields, and recognizes plain decimal numbers. YAML uses the host reader and its page, node and alias caps.

TOML is read by a small built-in reader: tables, arrays of tables, dotted and quoted keys, basic and literal strings (also multi-line), integers (with `_`, `0x`, `0o`, `0b`), floats, booleans, arrays and inline tables. Dates and times are kept as their text. A syntax error names its line (`toml line 3: ...`); a key written twice, a table written twice and values nested past 64 levels are refused. A key such as `__proto__` is plain data.

Caps (authored; strict in parentheses when lower): exploreChars 262144 (131072), exploreDepth 64 (32), exploreCsvRows 5000 (2500), exploreCsvCols 30 (20), exploreQueryChars 2000 (1000), exploreReaderQueryChars 500, exploreQueryDepth 100 (50), exploreQueryResults 10000 (5000), exploreRegexChars 2000, exploreRegexProgram 4000 (2000), exploreRegexRepeat 200, exploreQueryJsonChars 100000, exploreReaderSteps 200000 (100000), exploreReaderValues 400000 (200000), exploreReaderChars 1000000, exploreRowsPerNode 100, exploreSearchNodes 20000 (10000), exploreTableRows 200, exploreTableCols 12, exploreStringCut 120. Hosts can lower all caps.

Doccheck refuses unknown options, invalid JSON or YAML, malformed or unclosed CSV, duplicate headers, a missing CSV header or data row, too many columns/rows, too much data, nesting over the cap, query errors, unsupported syntax, too many query results, and work beyond the page budget.
