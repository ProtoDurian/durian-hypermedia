## Alignment grid: any size

Each axis has 2 to 6 names, and the two axes need not match: this grid has five columns and three rows. A grid with more names than that would have cells too small to read.

```alignment title="How far along is each part?"
x: idea .. sketch .. draft .. review .. shipped
y: small .. medium .. large
idea / small: A clock part
sketch / medium: A map part
draft / medium: Tier list
review / large: Animation in 3D
shipped / small "Done": Terminal
shipped / medium: Editor, File tree
```
