## Mouse actions

One mouse icon and the action. The button the action presses is filled: the left one for a click, the right one for a right click, the wheel for a middle click. A double click adds a "2", so it never looks like a single click. Scroll adds arrows by the wheel; drag, drop, hover and select add their own small mark.
