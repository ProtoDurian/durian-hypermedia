## Tier list

A tier list ranks items in rows, best first. Write one line per tier: its name, a colon, then its items with commas between them. A short note goes in brackets after an item; the page shows it when a reader taps or hovers the item. An LLM reads the same lines.

```tierlist title="Databases for a small team"
S: Postgres (does almost everything), SQLite (no server to run)
A: MySQL, "Redis, as a cache" (fast, but memory is dear)
B: MongoDB, DynamoDB
C: Cassandra (great at scale, hard to run small)
D: A spreadsheet
```
