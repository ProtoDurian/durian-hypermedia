## Tier list: three tiers, or seven

There is no limit of four or five. Three tiers are enough for a short list; seven fit a scale with many steps. Only the names on the `tiers:` line count.

```tierlist title="Is it worth doing?"
tiers: Yes [good], Maybe [warn], No [bad]
Yes: Cache the build, Add a sample
Maybe: Rewrite the docs site (a lot of work)
No: Support every browser ever
```

```tierlist title="How far along is each part?"
tiers: Shipped [good], Beta [c6], Alpha [c4], Prototype [c3], Sketch [c5], Idea [c7], Dropped [bad]
Shipped: Terminal, File tree
Beta: Editor
Alpha: Animation in 3D
Prototype: Tier list
Sketch: Voice over
Idea: A map part
Dropped: A clock part
```
