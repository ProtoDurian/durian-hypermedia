## Alignment grid

An alignment grid has two axes, each with a name at both ends and any names between (the classic one is lawful .. chaotic by good .. evil). The first name is the left (or top) end. Put items in a cell by its column and row names, `column / row: item, item`; a `"label"` before the colon names the cell.

```alignment title="Which kind of hero?"
x: lawful .. neutral .. chaotic
y: good .. neutral .. evil
lawful / good "Crusader": Paladin (keeps every oath), Cleric
neutral / good: Druid (looks after the land)
chaotic / good "Rebel": Bard (helps, breaks the rules)
neutral / neutral "Balance": Monk
lawful / evil "Tyrant": Warlock (a contract for everything)
chaotic / evil "Raider": Rogue (takes what it wants)
```
