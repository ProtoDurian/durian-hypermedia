## Still scene

Boxes joined by lines are an `animation`. With no `@step` line it stands still: drawn once, with no player. An LLM reads what it starts with and what is connected.

```animation
box cli "CLI"
box tc "template container"
cli -> tc "init call"
box out "project folder"
tc -> out "writes the files"
```
