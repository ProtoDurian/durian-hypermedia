# Venn with wrong lines

A region twice, a name in two regions, a count with the word first, a region of an unknown set and a fifth set: each refused with its line.

```venn title="Wrong lines"
set s0 "S0"
set s1 "S1"
set s2 "S2"
set s3 "S3"
s0 & s1: Name1
s0 & s1: other
s1: Name1
s2: people 4
nothing & s1: x
s3:
set s4 "S4"
```
